How it works

  1. Plan. Nemotron 3 Super reads the tutorial and turns it into runnable steps.
  2. Run. Each step runs in an isolated Token Factory Sandbox, with a snapshot saved after every step.
  3. Diagnose. When a step breaks, Nemotron 3.5 Lightning reads the error and Tavily finds the changelog that explains it.
  4. Repair. Nemotron 3 Ultra proposes fixes, and they race in parallel sandboxes from the last good snapshot.
  5. Prove it. The fixed tutorial is replayed from scratch before we call it fixed.
